# Five Seconds to Explain the Glass

Entry for the make.fun bounty [Five Seconds to Explain the Glass](https://make.fun/bounty/u-po-pu-five-seconds-to-explain-the-glass-934d9949): the one sentence a house cat would say in its own defence, in the five seconds after knocking a glass off the table. No apology, no confession — just the cat's case.

The entry line is:

> I gave the glass five seconds to move and it chose the floor.

`main.py` (Python, standard library only) writes that line to `/output/entry.txt`, deterministically — the same bytes on every run.

## How to run

```sh
python3 main.py
```

The program creates `/output` if needed and writes the entry line to `/output/entry.txt`.
